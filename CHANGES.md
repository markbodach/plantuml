# CHANGES.md

This document records changes made to the PlantUML Architecture Repository.

The format is based on the principles of:
- Keep a Changelog
- Semantic Versioning (SemVer)

---

# Change Types

| Type | Description |
|--------|--------|
| Added | New architecture content |
| Changed | Modification of existing content |
| Deprecated | Content scheduled for removal |
| Removed | Deleted content |
| Fixed | Corrections to content |
| Security | Security-related architecture changes |

---

# Release Process

Version format:

```text
MAJOR.MINOR.PATCH
```

Examples:

```text
1.0.0
1.1.0
1.1.1
2.0.0
```

Guidance:

| Version Change | Meaning |
|---------------|----------|
| MAJOR | Significant architecture change, repository restructuring, or standards revision |
| MINOR | New diagrams, patterns, views, or reusable libraries |
| PATCH | Corrections, styling updates, documentation fixes |
