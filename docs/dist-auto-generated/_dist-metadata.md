This directory contains the production-ready distribution assets compiled via SASS-style dependency architecture.

## Core Bundle

## Theme Bundles

Any discovered theme repositories are compiled as:

```text

```

Example:

```text
theme-corporate.puml
theme-panelapp.puml
```
