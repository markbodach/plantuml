
## Architecture Governance

All architecture diagrams should:

- Use the shared theme.
- Use reusable libraries where possible.
- Avoid hardcoded styling.
- Use approved architecture terminology.
- Maintain traceability across architecture viewpoints.
- Follow PanelApp architecture standards.

Changes to themes, libraries, or architecture standards should be reviewed as architecture governance artifacts before adoption.
